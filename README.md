# Personal Expense Tracker Backend

This is the Express/MongoDB backend for the Personal Expense Tracker app.

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```

2. Create a `.env` file with your configuration (see `.env` example).

3. Start the server:
   ```sh
   npm run dev
   ```

The backend will run at [http://localhost:5000](http://localhost:5000) by default.

## Features

- User authentication (register, login)
- Manage income and expense transactions
- RESTful API for frontend integration

Ensure MongoDB is running and accessible via your `MONGO_URI`.
